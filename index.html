Auto-Key-Spam · KeyForge Automation

Desktop automation, done right.

KeyForge turns raw key-pressing into a real toolkit: JSON sequences, randomized human-like intervals, per-window targeting, a global kill-switch, and dry-run simulation. Build a sequence below, simulate it, and download a file the desktop tool really runs.

Honest split — read this first: this web page cannot press keys. No website can — browsers have no access to your keyboard output. Everything on this page is a simulation (0 real key events). Real keypresses happen only when you download the JSON below and run it with the Python tool on your own desktop: python cli.py your-sequence.json.

JSON sequences

Define key sequences as data — version-controlled, shareable, editable.

Human-like timing

Randomized intervals between presses, no robotic patterns.

Kill-switch

Esc aborts instantly, F9 pauses. Automation never runs away from you.

Window targeting

Live runs abort if the target window is missing — keys never go to the wrong app by accident.

Dry-run mode

Simulate the full sequence with zero side effects before going live.

Action logging

Every press timestamped and logged for audit and debugging.

Sequence builder Builds a real, validated sequence — the same rules as the Python tool (one action per step, interval ≥ 0, repeats 1–10000). Your work auto-saves in this browser (localStorage) and never leaves your device.



To run it for real on your desktop:

pip install -r requirements.txt  then  python cli.py your-sequence.json --dry-run (safe check)  then  python cli.py your-sequence.json (live — Esc stops it, F9 pauses).

sequences/example.json — the real shipped file


{
  "countdown": 2,
  "name": "notepad typing demo",
  "steps": [
    {"type": "text", "text": "Hello from KeyForge. ", "interval": 0.5},
    {"keys": ["enter"], "interval": 0.3},
    {"keys": ["h", "e", "l", "l", "o"], "interval": [0.05, 0.15], "repeats": 3},
    {"hotkey": ["ctrl", "s"], "interval": [1.0, 1.5]}
  ],
  "window": "Untitled - Notepad"
}


This is the exact file in the repo — copy it or download it from GitHub. Earlier versions of this page showed a different example using fields (wait_after, jitter) the tool never supported; that stale example has been removed.



How KeyForge compares




ToolWhat it hasWhere KeyForge differs


AutoHotkey (free, Windows)Full scripting language, hotkeys, compiles to .exeKeyForge is simpler JSON + a browser builder; no scripting language to learn, but also no mouse control or conditionals yet.


Pulover's Macro Creator (free, Windows)Visual macro builder, recording, exports AutoHotkey scriptsKeyForge's builder runs in any browser and exports runnable JSON; it does not record mouse/keyboard input.


TinyTask (free, Windows)Tiny recorder: record once, replay; no installKeyForge sequences are editable data with randomized timing and a kill-switch; TinyTask has no sequence editing or window-target abort.


AutoIt (free, Windows)Scripting + GUI automation, pixel/window functionsKeyForge is cross-platform Python and JSON-first; AutoIt is Windows-only and script-first.


Auto Keyboard by MurGee (trial, then paid)Single-key repetition, global hotkey, system trayKeyForge is free, multi-step sequences with hotkeys and text; MurGee presses one key only.




No backend, account, or payment is needed for KeyForge: the page stores sequences in your browser only, and the desktop tool runs locally. Nothing here is a live user count or usage statistic — there are none.



Responsible use: KeyForge is built for legitimate automation — accessibility assistance, UI testing, and productivity workflows. Do not use it to spam, harass, or violate any platform's terms of service.
